# Concept to Creation

**Version 0.2.0 · Design draft for feedback.**

An industry-neutral Agent Skills-format instruction package for helping people discover, research existing approaches, visualize, design and document app ideas, then plan incremental development in independently testable stages.

## Contents
- `SKILL.md` — activation and core operating behavior.
- `references/conversation-playbook.md` — adaptive conversation guidance.
- `references/research-playbook.md` — lightweight evidence-based existing-product/workflow comparison before depiction.
- `references/project-documents.md` — document selection and consistency rules.
- `references/quality-gates.md` — evidence and handoff criteria.
- `assets/` — minimal Markdown templates used to create project deliverables.
- [`tests/scenarios.md`](tests/scenarios.md) — proposed manual tests; none executed.

## Design principles
Research comparable apps and workflows before early visual depiction; user feedback before polishing; behavior before implementation; decisions distinguished from proposals; proportionate docs; vertical build stages; evidence-based review; explicit authorization boundaries.

## Review the draft

Start with [SKILL.md](SKILL.md). To evaluate how the skill behaves, try a [manual scenario](tests/scenarios.md) in a fresh conversation with a compatible agent. Tool availability varies by agent.

Share feedback in [GitHub Issues](https://github.com/shakeshoppeballito-code/concept-to-creation/issues/new). Include the scenario or prompt, the agent you used, what happened, and what you expected. A short example with private details removed is enough.

The package follows the [Agent Skills format](https://agentskills.io/specification). The manual scenarios are still pending. An open-source license has yet to be selected.
